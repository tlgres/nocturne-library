# 밤의 도서관에 들어가기

[[NORMAL]]
■ 문서가 화면이 되는 순간

Nocturne의 원본은 여전히 평범한 Markdown 문서다. 중요한 것은 문서 자체에 장식과 화면 배치를 박아 넣지 않는 것이다. 같은 원고가 Archive View에서는 한 편의 글이 되고, Study View에서는 한 단계씩 넘겨 읽는 강의가 된다.
[[END]]

[[FAST]]
지금 보고 있는 웹 Reader의 첫 번째 목표는 Extension의 모든 기능을 복제하는 것이 아니다. 우선 긴 글을 편안하게 읽고, 의미 단위 사이를 이동하고, 중요한 구간에서 자연스럽게 속도를 바꿀 수 있으면 충분하다.
[[END]]

[[FOCUS]]
■ 콘텐츠와 표현의 분리

Format 1.0은 무엇이 NORMAL이고 무엇이 FOCUS인지 말하지만, 그것이 몇 픽셀의 테두리를 가져야 하는지는 말하지 않는다. **콘텐츠의 의미와 화면의 표현을 분리하는 것**이 Nocturne Core를 따로 만든 이유다.
[[END]]

[[STOP]]
한 파일이 서로 다른 두 화면에서 읽힐 수 있다면, 앞으로 디자인을 완전히 바꾸더라도 과거의 강의는 다시 작성할 필요가 없다. 이것이 장기 보관용 포맷에서 가장 중요한 성질 중 하나다.
[[END]]

[[SIDE]]
훗날 별자리나 캐릭터, 창밖 풍경 같은 장식이 추가되어도 이 원칙은 바뀌지 않는다. 그러한 요소는 renderer가 담당한다.
[[END]]
