# 의미에 속도를 부여하기

[[NORMAL]]
■ 모든 문장이 같은 무게를 갖지는 않는다

긴 강의를 처음부터 끝까지 같은 밀도로 읽으면 독자가 먼저 지친다. Nocturne은 내용을 삭제하는 대신, 어느 부분을 빠르게 지나가고 어느 부분에서 멈출지를 문서에 기록한다.
[[END]]

[[FOCUS]]
FOCUS는 형광펜이 아니다. 글에서 가장 화려한 부분을 표시하는 태그도 아니다. 독자가 **인지적 자원을 조금 더 투입해야 하는 지점**을 표시한다. 따라서 FOCUS가 지나치게 많아지면 오히려 의미가 사라진다.
[[END]]

[[STOP]]
지금 읽은 내용을 한 문장으로 다시 말할 수 있는가? STOP은 반드시 문제를 내기 위한 장치가 아니라, 다음 문단으로 넘어가기 전에 사고의 관성을 잠깐 끊는 장치다.
[[END]]
