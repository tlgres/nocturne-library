# 11강. 대포를 가져오지 말라고는 안 했다 — Fourier, Laplace, Mellin transform

[[NORMAL]]
■ 오늘의 범죄 현장

다음을 보자.

\[
I=
\int_{-\infty}^{\infty}
\frac{\cos bx}{x^2+a^2}\,dx.
\]

우리는 이미 7강에서 residue theorem으로

\[
I=\frac{\pi}{a}e^{-a|b|}
\]

를 얻었다.

그런데 다른 사람은 contour를 그리지 않는다. 대신 이렇게 말한다.

“\(1/(x^2+a^2)\)의 Fourier transform을 알고 있는데?”

계산이 끝난다.

또

\[
\int_0^\infty \frac{x^{s-1}}{1+x}\,dx
\]

를 보면 Beta function으로 갈 수도 있지만, 어떤 사람에게는 이것이 처음부터 Mellin transform이다.

오늘은 개별 적분을 공격하는 기술보다 더 큰 무기를 쓴다.

\[
\boxed{
\text{함수 전체를 다른 좌표계로 옮겨놓는다.}
}
\]

Fourier transform은 진동의 좌표계로, Laplace transform은 지수감쇠의 좌표계로, Mellin transform은 스케일의 좌표계로 함수를 번역한다.

적분 하나를 푸는 데 함수해석용 대포를 들고 오는 날이다.
[[END]]

MUTE|normal|이미 계산된 함수 전체의 정보를 재사용하는 것이다. 부당하게 강력한 건 맞다.

[[FOCUS]]
■ 적분변환은 무엇을 하는가

적분변환은 대략

\[
F(s)=\int K(s,x)f(x)\,dx
\]

꼴이다.

함수 \(f(x)\)를 새로운 함수 \(F(s)\)로 바꾼다.

핵심은 kernel \(K(s,x)\)의 선택이다.

Fourier transform에서는

\[
K(\xi,x)=e^{-i\xi x},
\]

Laplace transform에서는

\[
K(s,t)=e^{-st},
\]

Mellin transform에서는

\[
K(s,x)=x^{s-1}.
\]

각 kernel은 서로 다른 종류의 구조를 diagonalize한다.

Fourier는 미분과 translation에 강하고,

Laplace는 미분방정식과 초기조건에 강하며,

Mellin은 scaling과 power law에 강하다.

즉 transform은 단순히 적분 공식을 하나 더 외우는 것이 아니다.

\[
\boxed{
\text{문제가 단순해지는 좌표계를 선택하는 일이다.}
}
\]
[[END]]

[[NORMAL]]
■ 괴적분 1 — Gaussian은 Fourier transform을 해도 Gaussian이다

Fourier transform convention을

\[
\widehat f(\xi)
=
\int_{-\infty}^{\infty}
f(x)e^{-i\xi x}\,dx
\]

로 잡자.

4강과 6강에서 이미

\[
\int_{-\infty}^{\infty}
e^{-x^2}e^{i bx}\,dx
=
\sqrt\pi e^{-b^2/4}
\]

를 계산했다.

부호만 바꾸어도 Gaussian의 짝대칭 때문에 결과는 같다.

따라서

\[
\boxed{
\mathcal F[e^{-x^2}](\xi)
=
\sqrt\pi e^{-\xi^2/4}.
}
\]

Gaussian을 Fourier transform했더니 다시 Gaussian이 나왔다.

이것은 단순히 예쁜 공식 하나가 아니다. Fourier transform이 왜 열방정식, 확률론, 양자역학에서 Gaussian과 끊임없이 엮이는지를 보여준다.
[[END]]

[[FOCUS]]
■ Fourier transform은 미분을 곱셈으로 바꾼다

적절한 조건 아래

\[
\mathcal F[f'](\xi)
=
i\xi\widehat f(\xi).
\]

더 일반적으로

\[
\mathcal F[f^{(n)}](\xi)
=
(i\xi)^n\widehat f(\xi).
\]

즉 \(x\)-공간에서 귀찮은 미분연산자가 Fourier 공간에서는 단순히

\[
\times(i\xi)
\]

가 된다.

2강에서

\[
e^{i\xi x}
\]

가 미분연산자의 고유함수라고 했다.

Fourier transform은 임의의 함수를 바로 그 고유함수들의 연속적인 합으로 분해하는 장치다.

그래서 미분방정식이 Fourier 공간에서 대수방정식으로 변한다.

\[
\boxed{
\text{복잡한 연산자를 고유함수 좌표계에서 곱셈으로 만든다.}
}
\]

2강에서 보았던 작은 트릭이 이제 하나의 거대한 이론이 된 것이다.
[[END]]

[[CAST]]
ED|realize|2강의 \(e^{ibx}\)가 그냥 계산 편의를 위한 복소수 장난이 아니었군.
MUTE|thinking|그렇다. Fourier analysis 전체가 그 복소 지수함수들을 좌표축으로 쓰는 셈이다.
[[ENDCAST]]

[[NORMAL]]
■ 괴적분 2 — residue 없이 \(\int \cos bx/(x^2+a^2)\)

함수

\[
f(x)=e^{-a|x|},
\qquad a>0
\]

의 Fourier transform을 계산해 보자.

짝함수이므로

\[
\widehat f(\xi)
=
2\int_0^\infty e^{-ax}\cos(\xi x)\,dx.
\]

2강의 감쇠진동 적분을 쓰면

\[
\widehat f(\xi)
=
\frac{2a}{a^2+\xi^2}.
\]

즉 transform pair

\[
e^{-a|x|}
\quad\longleftrightarrow\quad
\frac{2a}{a^2+\xi^2}
\]

를 얻는다.

Fourier inversion을 적용하면 반대로

\[
\boxed{
\int_{-\infty}^{\infty}
\frac{e^{i\xi x}}{x^2+a^2}\,dx
=
\frac{\pi}{a}e^{-a|\xi|}
}
\]

가 나온다.

실수부를 취하면

\[
\boxed{
\int_{-\infty}^{\infty}
\frac{\cos(\xi x)}{x^2+a^2}\,dx
=
\frac{\pi}{a}e^{-a|\xi|}.
}
\]

7강에서는 pole 하나를 셌다. 오늘은 이미 알고 있는 transform pair를 뒤집었다.
[[END]]

[[SIDE]]
Fourier transform의 상수계수는 convention에 따라 달라진다.

어떤 책은 \(2\pi\)를 forward transform에 넣고, 어떤 책은 inverse에 넣으며, 어떤 책은 양쪽에 \(1/\sqrt{2\pi}\)를 나눠 가진다.

따라서 transform table을 사용할 때는 반드시 convention을 확인해야 한다.

괴적분에서 가장 허무한 사고는 모든 구조를 맞게 보고 마지막에 \(2\pi\) 하나를 잃어버리는 것이다.
[[END]]

[[FOCUS]]
■ 첫 번째 냄새: 진동하는 적분은 Fourier에게 넘겨라

다음과 같은 적분은 Fourier transform 냄새가 강하다.

\[
\int_{-\infty}^{\infty}
f(x)\cos(\xi x)\,dx,
\]

\[
\int_{-\infty}^{\infty}
f(x)\sin(\xi x)\,dx,
\]

\[
\int_{-\infty}^{\infty}
f(x)e^{-i\xi x}\,dx.
\]

특히 \(f\)가 Gaussian, exponential, rational function, rectangle, sinc 같은 잘 알려진 함수라면 transform table이 이미 답을 알고 있을 가능성이 높다.

이때 중요한 질문은

\[
\text{“이 적분을 어떻게 계산하지?”}
\]

가 아니라

\[
\boxed{
\text{“나는 지금 어느 함수의 Fourier transform 값을 보고 있는가?”}
}
\]

이다.
[[END]]

[[NORMAL]]
■ Fourier transform의 또 다른 범죄: convolution

두 함수의 convolution을

\[
(f*g)(x)
=
\int_{-\infty}^{\infty}
f(t)g(x-t)\,dt
\]

라고 하자.

이것은 보기만 해도 적분이다.

그런데 Fourier transform을 하면

\[
\boxed{
\mathcal F[f*g]
=
\widehat f\,\widehat g.
}
\]

즉 복잡한 convolution integral이 단순한 곱셈으로 변한다.

반대로

\[
\mathcal F[fg]
\]

는 transform들의 convolution이 된다.

적분을 직접 계산하지 않고 transform 공간에서 곱한 뒤 다시 돌아오는 것이 가능하다.

확률론에서는 독립확률변수 합의 density가 convolution으로 주어지므로, characteristic function을 곱하는 것과 같은 구조다.

5강에서 언급한 독립성이 여기서 Fourier transform과 합류한다.
[[END]]

[[NORMAL]]
■ 괴적분 3 — Laplace transform은 적분표가 아니라 시간축의 대포다

Laplace transform은

\[
\boxed{
\mathcal L[f](s)
=
\int_0^\infty
e^{-st}f(t)\,dt
}
\]

로 정의된다.

2강에서 이미

\[
\int_0^\infty
e^{-st}\sin bt\,dt
=
\frac{b}{s^2+b^2}
\]

를 보았다.

즉

\[
\boxed{
\mathcal L[\sin bt](s)
=
\frac{b}{s^2+b^2}
}
\]

다.

마찬가지로

\[
\boxed{
\mathcal L[\cos bt](s)
=
\frac{s}{s^2+b^2}.
}
\]

처음에는 단순히 감쇠 진동 적분처럼 보였지만, Laplace language에서는 이것이 함수 전체의 transform이다.
[[END]]

[[FOCUS]]
■ Laplace transform은 초기조건까지 같이 먹는다

Fourier transform처럼 Laplace transform도 미분을 단순화한다.

\[
\mathcal L[f'](s)
=
sF(s)-f(0).
\]

또

\[
\mathcal L[f''](s)
=
s^2F(s)-sf(0)-f'(0).
\]

미분이 \(s\)의 곱셈으로 바뀌면서 초기조건이 자동으로 따라붙는다.

그래서 초기값문제

\[
y''+\omega^2y=g(t)
\]

를 Laplace transform하면 미분방정식이 \(Y(s)\)에 대한 대수방정식으로 변한다.

즉 Laplace transform은 적분 계산도구이면서 동시에 미분방정식 해석기다.

\[
\boxed{
\text{시간영역의 미분을 복소주파수 영역의 대수로 바꾼다.}
}
\]
[[END]]

[[NORMAL]]
■ 적분값을 Laplace transform의 특수값으로 읽기

예를 들어

\[
I=
\int_0^\infty
e^{-3x}x^4\,dx
\]

를 보자.

Gamma function으로 해도 된다.

하지만

\[
\mathcal L[x^n](s)
=
\frac{n!}{s^{n+1}}
\]

를 알고 있다면

\[
I
=
\mathcal L[x^4](3)
=
\frac{4!}{3^5}.
\]

따라서

\[
\boxed{
I=\frac{8}{81}.
}
\]

적분값 하나가 transform의 함수값 하나가 되었다.

9강에서는 Gamma function으로 보았고, 오늘은 Laplace transform으로 본다.

같은 적분의 정체가 또 바뀌었다.
[[END]]

[[FOCUS]]
■ 그리고 오늘의 진짜 괴물: Mellin transform

Mellin transform을

\[
\boxed{
\mathcal M[f](s)
=
\int_0^\infty
x^{s-1}f(x)\,dx
}
\]

로 정의한다.

처음 보면 Gamma integral과 거의 똑같다.

실제로

\[
f(x)=e^{-x}
\]

이면

\[
\mathcal M[e^{-x}](s)
=
\Gamma(s).
\]

즉 Gamma function 자체가 exponential function의 Mellin transform이다.

Mellin transform은 괴적분 세계에서 특히 강력하다.

왜냐하면 적분에 자주 등장하는

\[
x^{s-1}
\]

이라는 power가 바로 kernel이기 때문이다.
[[END]]

[[NORMAL]]
■ Fourier가 translation을 보면, Mellin은 scaling을 본다

Mellin transform의 본질을 보려면 변수변환

\[
x=e^t
\]

를 하자.

그러면

\[
dx=e^t\,dt
\]

이고

\[
x^{s-1}dx=e^{st}\,dt.
\]

따라서

\[
\mathcal M[f](s)
=
\int_{-\infty}^{\infty}
e^{st}f(e^t)\,dt.
\]

즉 로그좌표 \(t=\log x\)에서는 Mellin transform이 양방향 Laplace/Fourier transform과 비슷해진다.

1강에서

\[
x\mapsto\frac1x
\]

가 로그좌표에서는

\[
t\mapsto-t
\]

가 된다고 했다.

그때 잠깐 등장했던 Mellin transform이 이제 돌아왔다.

\[
\boxed{
\text{Mellin transform은 곱셈적 세계의 Fourier transform이다.}
}
\]
[[END]]

[[CAST]]
ED|realize|그러면 1강의 \(x\leftrightarrow1/x\) 대칭이 여기서는 아주 자연스러운 대칭이 되는군.
MUTE|thinking|그렇다. Mellin은 크기와 스케일의 변환을 자연스럽게 읽는다.
[[ENDCAST]]

[[NORMAL]]
■ 괴적분 4 — \(\int x^{s-1}/(1+x)\)

다음을 다시 만나자.

\[
I(s)
=
\int_0^\infty
\frac{x^{s-1}}{1+x}\,dx,
\qquad 0<\Re s<1.
\]

9강에서는 Beta function과 reflection formula로

\[
I(s)=\frac{\pi}{\sin\pi s}
\]

를 얻었다.

Mellin language에서는 더 짧게 말할 수 있다.

\[
I(s)
=
\mathcal M\left[\frac1{1+x}\right](s).
\]

즉 transform pair

\[
\boxed{
\mathcal M\left[\frac1{1+x}\right](s)
=
\pi\csc(\pi s)
}
\]

이다.

괴적분 하나가 Mellin transform table의 한 줄이 되었다.
[[END]]

[[FOCUS]]
■ 두 번째 냄새: power law가 매개변수로 붙어 있다

다음 형태는 Mellin transform의 강한 신호다.

\[
\int_0^\infty
x^{s-1}f(x)\,dx.
\]

특히 \(s\)가 변수로 남아 있으면 거의 대놓고 Mellin transform이다.

이런 적분에서 \(s\)를 미분하면

\[
\frac{d}{ds}x^{s-1}
=
x^{s-1}\log x
\]

이므로 로그가 튀어나온다.

따라서 Mellin transform 하나를 알고 있으면 \(\log x\), \(\log^2x\)가 들어간 적분도 \(s\)-미분으로 생성할 수 있다.

3강의 Feynman trick과 Mellin transform이 정확히 맞물리는 지점이다.
[[END]]

[[NORMAL]]
■ 괴적분 5 — 로그 적분을 Mellin transform에서 미분해 만든다

앞의 공식

\[
I(s)
=
\int_0^\infty
\frac{x^{s-1}}{1+x}\,dx
=
\pi\csc(\pi s)
\]

를 \(s\)로 미분하자.

그러면

\[
I'(s)
=
\int_0^\infty
\frac{x^{s-1}\log x}{1+x}\,dx.
\]

오른쪽은

\[
I'(s)
=
-\pi^2
\csc(\pi s)\cot(\pi s).
\]

따라서

\[
\boxed{
\int_0^\infty
\frac{x^{s-1}\log x}{1+x}\,dx
=
-\pi^2
\csc(\pi s)\cot(\pi s)
}
\]

이다.

예를 들어 \(s=1/2\)이면

\[
\cot\frac{\pi}{2}=0
\]

이므로

\[
\boxed{
\int_0^\infty
\frac{x^{-1/2}\log x}{1+x}\,dx
=
0.
}
\]

1강의 inversion symmetry로도 예상할 수 있는 결과가 Mellin transform의 미분으로 자동 생성된다.
[[END]]

[[FOCUS]]
■ transform은 다른 기법들을 저장하는 창고다

여기서 중요한 사실이 드러난다.

Fourier transform 안에는 복소화와 진동적분이 들어 있다.

Laplace transform 안에는 감쇠지수와 Gamma-type integral이 들어 있다.

Mellin transform 안에는 scaling, Beta/Gamma, \(x\leftrightarrow1/x\), logarithmic differentiation이 들어 있다.

즉 앞선 강의들의 trick들이 transform theory 안에서는 개별 기행이 아니라 체계적인 연산법이 된다.

\[
\boxed{
\text{흑마술을 충분히 많이 모으면 결국 이론이 된다.}
}
\]
[[END]]

[[NORMAL]]
■ Parseval과 Plancherel — 적분을 다른 공간에서 계산하기

Fourier transform의 더욱 부당한 성질을 보자.

적절한 convention에서 Plancherel theorem은

\[
\int_{-\infty}^{\infty}|f(x)|^2dx
=
\frac1{2\pi}
\int_{-\infty}^{\infty}
|\widehat f(\xi)|^2d\xi
\]

라고 말한다.

즉 한 공간에서의 제곱적분값을 다른 공간에서 계산해도 된다.

원래 적분이 복잡한데 Fourier transform이 단순하면, transform 공간으로 도망가 적분을 계산한 뒤 돌아올 수 있다.

이것은 contour deformation보다 한 단계 더 심하다.

경로만 바꾸는 것이 아니라 함수 자체의 표현공간을 바꾼다.
[[END]]

[[SIDE]]
이 원리는 신호처리에서는 에너지 보존으로 읽힌다.

시간영역에서 신호의 총 에너지를 계산해도 되고, 주파수영역에서 계산해도 같은 값이 나온다.

양자역학에서는 위치공간과 운동량공간의 파동함수가 Fourier transform으로 연결된다.

적분변환은 계산트릭이 아니라 동일한 객체를 서로 다른 representation에서 보는 방법이다.
[[END]]

■ 예제 — sinc의 제곱 적분

유명한 적분을 하나 보자.

\[
I=
\int_{-\infty}^{\infty}
\left(\frac{\sin x}{x}\right)^2dx.
\]

직접 적분하기 상당히 불편하다.

그런데 rectangle function과 sinc function은 Fourier transform pair다.

적절한 convention에서 구간 \([-1,1]\)의 indicator function을

\[
f(t)=
\begin{cases}
1,&|t|\le1,\\
0,&|t|>1
\end{cases}
\]

라 하면

\[
\widehat f(\xi)
=
\int_{-1}^{1}e^{-i\xi t}dt
=
\frac{2\sin\xi}{\xi}.
\]

Plancherel theorem을 쓰면

\[
\int_{-\infty}^{\infty}|f(t)|^2dt
=
\frac1{2\pi}
\int_{-\infty}^{\infty}
|\widehat f(\xi)|^2d\xi.
\]

왼쪽은 그냥 2다.

따라서

\[
2
=
\frac1{2\pi}
\int_{-\infty}^{\infty}
4\left(\frac{\sin\xi}{\xi}\right)^2d\xi.
\]

그러므로

\[
\boxed{
\int_{-\infty}^{\infty}
\left(\frac{\sin x}{x}\right)^2dx
=
\pi.
}
\]

실수축에서 sinc를 적분하지 않았다. 직사각형의 길이를 쟀다.
[[END]]

■ 이것이 transform method의 미학이다

좋은 transform 문제에서는 원래 공간에서 어려운 연산이 다른 공간에서 우스울 정도로 쉬워진다.

미분은 곱셈이 되고,

convolution은 곱셈이 되고,

Gaussian은 Gaussian으로 남고,

scaling은 Mellin 공간에서 단순한 지수인자가 되며,

복잡한 적분값은 transform의 특정 점에서의 함수값이 된다.

따라서 transform을 사용할 때 가장 중요한 질문은

\[
\boxed{
\text{어느 공간에서 이 문제가 가장 바보같아지는가?}
}
\]

이다.

원래 표현에 충성할 이유는 없다.
[[END]]

[[NORMAL]]
■ 세 transform을 구별하는 법

Fourier transform은

\[
e^{-i\xi x}
\]

를 kernel로 쓴다.

진동, translation, frequency가 핵심이면 Fourier를 의심한다.

Laplace transform은

\[
e^{-sx}
\]

를 kernel로 쓴다.

\(x\ge0\), 감쇠, 시간발전, 초기값문제가 핵심이면 Laplace가 자연스럽다.

Mellin transform은

\[
x^{s-1}
\]

를 kernel로 쓴다.

power law, scaling, \(0\)과 \(\infty\)의 관계, Gamma/Beta 구조가 보이면 Mellin이 강하다.

물론 실제 문제에서는 이 셋이 서로 연결된다.

로그변수를 취하면 Mellin은 Fourier/Laplace와 닮아지고, Laplace transform도 복소주파수 축을 따라 Fourier와 이어진다.
[[END]]

[[STOP]]
다음 세 적분을 보자.

\[
A(\xi)=
\int_{-\infty}^{\infty}
f(x)e^{-i\xi x}dx,
\]

\[
B(s)=
\int_0^\infty
f(x)e^{-sx}dx,
\]

\[
C(s)=
\int_0^\infty
x^{s-1}f(x)dx.
\]

각각 Fourier, Laplace, Mellin transform이다.

이 세 식을 외우는 것보다 중요한 구별은 다음이다.

Fourier는 덧셈적 이동의 세계,

Mellin은 곱셈적 확대·축소의 세계,

Laplace는 감쇠와 시간진화의 세계에 자연스럽다.
[[END]]

[[NORMAL]]
■ Mellin transform과 asymptotics

Mellin transform은 단순 적분계산을 넘어 함수의 \(x\to0\) 및 \(x\to\infty\) 거동을 분석하는 데 강력하다.

예를 들어

\[
\mathcal M[f](s)
=
\int_0^\infty x^{s-1}f(x)dx
\]

의 pole 위치와 residue는 원래 함수의 asymptotic expansion과 연결되는 경우가 많다.

즉 복소 \(s\)-평면의 singularity를 읽어 원래 함수의 크기변화를 알아낼 수 있다.

7강에서는 \(z\)-평면의 pole이 실수적분 값을 알려주었다.

Mellin analysis에서는 transform 평면의 pole이 asymptotics를 알려준다.

residue theorem이 다시 돌아온다.
[[END]]

[[SIDE]]
이 아이디어는 analytic number theory에서 매우 강력하다.

수열의 합, Dirichlet series, zeta function, counting function 사이를 적분변환으로 연결한 뒤 복소평면의 pole과 contour shift를 이용해 asymptotic formula를 뽑아낸다.

즉 “괴적분을 풀기 위해 residue를 센다”는 소박한 수법이 충분히 커지면 소수분포 같은 문제에도 등장한다.

강의 제목은 여전히 적분이지만, 이쯤 오면 적분은 수학 분야들 사이의 통로에 가깝다.
[[END]]

[[NORMAL]]
■ 마지막 예제 — Gamma function을 Mellin transform에서 다시 보기

\[
\Gamma(s)
=
\int_0^\infty
x^{s-1}e^{-x}dx
\]

는

\[
\mathcal M[e^{-x}](s)
\]

다.

이제 scaling을 적용해 보자.

\[
\int_0^\infty
x^{s-1}e^{-ax}\,dx,
\qquad a>0.
\]

\(u=ax\)를 쓰면

\[
x=\frac ua,
\qquad
dx=\frac{du}{a}.
\]

따라서

\[
\boxed{
\int_0^\infty
x^{s-1}e^{-ax}\,dx
=
a^{-s}\Gamma(s).
}
\]

Mellin transform에서 scaling은 단순히 \(a^{-s}\)라는 곱셈인자로 나타났다.

이것이 Mellin transform이 scale-invariant 문제에 그렇게 잘 맞는 이유다.
[[END]]

■ 오늘의 핵심 패턴

다음 냄새를 기억하자.

\[
e^{-i\xi x}
\]

가 보이면 Fourier.

\[
e^{-sx}
\]

가 보이면 Laplace.

\[
x^{s-1}
\]

가 보이면 Mellin.

진동적분이면 Fourier transform table을 의심한다.

초기값 미분방정식과 감쇠적분이면 Laplace를 의심한다.

\(0\)부터 \(\infty\), power law, Gamma/Beta, \(\log x\), \(x\leftrightarrow1/x\)가 얽히면 Mellin을 의심한다.

그리고 무엇보다

\[
\boxed{
\text{적분 하나가 어떤 transform의 특수값인지 먼저 확인하라.}
}
\]

이미 누군가 함수 전체를 계산해 두었을지도 모른다.
[[END]]

[[NORMAL]]
■ 범행 기록

오늘은 개별 적분을 공격하는 것을 거의 포기했다.

Gaussian을 Fourier transform하여 다시 Gaussian을 얻었다.

\[
\frac1{x^2+a^2}
\]

의 oscillatory integral은 transform pair를 뒤집어 계산했다.

\[
\sin bx,\ \cos bx,\ x^n
\]

의 감쇠적분은 Laplace transform의 함수값으로 읽었다.

\[
\frac{x^{s-1}}{1+x}
\]

는 Mellin transform이 되었고, \(s\)로 미분하자 \(\log x\)가 들어간 적분이 자동으로 생성되었다.

그리고

\[
\int_{-\infty}^{\infty}
\left(\frac{\sin x}{x}\right)^2dx
\]

는 Plancherel theorem을 이용해 직사각형 함수의 길이로 바꾸어

\[
\pi
\]

를 얻었다.

오늘의 규칙은 이것이다.

\[
\boxed{
\text{문제가 어려운 공간에서 계속 싸우지 말라. transform해서 다른 공간으로 도망가라.}
}
\]

이제 무기고는 거의 완성되었다.

대칭, 복소화, 매개변수 미분, 차원 상승, 확률론, contour deformation, residue, unit circle, 특수함수, 무한급수, 적분변환.

다음 강의는 마지막이다.

새로운 기술을 하나 더 배우기보다는, 적분 하나를 가운데 놓고 여러 사람이 달려들 것이다.

누군가는 대칭으로,

누군가는 Feynman trick으로,

누군가는 Fourier transform으로,

누군가는 residue theorem으로 죽인다.

그리고 가장 짧은 풀이, 가장 아름다운 풀이, 가장 부당한 풀이, 가장 미친 풀이를 가려본다.

이제 아무도 정상적으로 적분하지 않는다.
